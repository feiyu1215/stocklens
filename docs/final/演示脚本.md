# Demo Script

**目标时长 100–130 秒**（作业允许 60–180 秒）。录制方式：**对一个真实用户完成核心任务的过程录屏**，不使用 Guided Demo 代替——Guided Demo 是产品内的新手引导，不是本视频。

- 分辨率：1440×900（或 1080p），MP4 / H.264，目标 ≤ 12 MB
- 允许：剪掉等待时间、简单转场、字幕条、淡入淡出
- 禁止：用 PPT 讲稿代替产品体验；伪造中间财务结果；用别家公司的数据冒充

**录制入口（2026-10-09 已收敛）**：`https://stocklens-blush.vercel.app/`
（旧脚本从这里开始就落到一张孤立的画布上；现在先落首页，故事才讲得完整。）

---

## 本版改动的一句话说明

旧故事是"打开一张画布，往里钻"。新主线是**一次完整的研究来回**：从首页选公司 → 进入研究空间把结论追到证据 → 带着这家公司回研究库 → 再研究一家 → 并排对比 → 让 AI 组织摘要 → 随时用底部输入条兜底。中间每一步都能回跳，不留死胡同。

## 分镜表

### 0–8s ｜ 开场：从"选公司"开始，而不是从一张结论开始

**画面**：首页 `/`。鼠标依次掠过左上品牌标、右上「打开示例画布 →」、中央搜索框与三个建议问题，不做点击。

**字幕**：`StockLens｜AI Native 个股证据诊断`

### 8–20s ｜ 秒开示例画布：录制样本，不是空等

**画面**：点右上「打开示例画布 →」→ 落进美的集团的研究空间 → 顶栏出现琥珀色**录制示例**徽标 → 轻微平移，缓缓掠过若干研究维度。

**字幕**：`示例数据秒开用于演示；公司切换与追问都是实时调用`

### 20–30s ｜ 结论 → 证据 → 口径

**画面**：点任意一个维度 → 展开阅读区 → 停在一条带 `FACT POSITIVE` / `INFERENCE` 标签的结论上 → 点它身上的证据锚点 ①②③ → 证据区切到该证据，依次扫过：指标与数值、期次对比（`2026-Q2 vs 2025-Q2`）、来源与 `VERIFIED`、展开 `CALCULATION` 看口径。

**字幕**：`每条结论都能回到底层数据、期次与统计口径`

### 30–40s ｜ AI 解释证据，不替代事实

**画面**：在右侧 AI 研究助手里问「这条结论的证据边界在哪里？」→ 回答出现：先给边界，再分「可以确认 / 证据推断 / 仍不能确认」→ 点回答里的证据编号芯片，画布对应位置被点到。

**字幕**：`AI 只解释已经存在的证据；依据不足时返回 UNKNOWN`

### 40–48s ｜ 研究可以带走

**画面**：顶栏「导出笔记」→ 打印版页面出现（含结论、证据、口径与免责声明）→ 关闭回画布。

**字幕**：`研究过程可导出为可打印的研究笔记`

> 若录制环境这一步不在顶栏可见，直接跳过本幕——不要为了凑镜头伪造界面。

### 48–62s ｜ 带着这家公司回研究库

**画面**：点左上品牌标回首页 → 点右上 ▦ 进研究库 → 表格里出现刚才看过的美的（**打开示例画布会自动把这家公司存进本机**）→ 开启「对比」模式选中它。

**字幕**：`研究库保存本机研究过的公司，来回不掉线`

### 62–78s ｜ 第二家公司：这一次走真实链路

**画面**：在研究库/首页搜索一家真实公司（例如招商银行 600036.SH）→ 进入研究空间 → **保留完整的等待过程**：点击 → 全屏研究过渡（显示真实已等待秒数）→ 真正落在这家公司的画布上，掠过它与美的不同的维度结构。

**字幕**：`不同公司类型对应不同的研究结构；15–30 秒真实取数，不用假进度`

### 78–95s ｜ 双公司对比：可比才比

**画面**：回研究库 → 对比模式下选中两家公司 → 进对比页 → 依次掠过三种可比性标注：**可比较**（同报告期，给差值）、**并列参考**（报告期不同，不算差值）、**不可比**（数据缺失，不推导）→ 在缺失处停留一下，展示「—」与横幅说明。

**字幕**：`数据缺失就以「—」展示，绝不当作 0 参与比较`

### 95–110s ｜ AI 摘要：显式触发，且只组织已验证的事实

**画面**：点「生成对比摘要」→ 摘要出现，每句话都挂着它引用的指标 → 点其中一个数字回挂到对比表对应行 → 扫一眼摘要结尾对"哪些指标没进结论"的说明。

**字幕**：`摘要只组织已验证的数值，每个数字都要回表核对`

> 若上游模型偶发失败，产品会降级为确定性摘要或给出明确的失败态——**如实保留**，不要重录掩盖。

### 110–120s ｜ 兜底：任何一面都能开口问

**画面**：切到首页或研究库 → 底部常驻输入条 → 输入「回到研究库」然后点执行卡片；再输入「ROE 是什么意思」——依次展示导航类与概念解释类两路回答。

**字幕**：`底部输入条在首页、研究库、对比页都在；规则优先，AI 兜底`

### 120–128s ｜ 收尾

**画面**：淡出到浅色底，两行字居中。

**字幕**：
```
Evidence first.
Conclusions second.
        StockLens
```

## 剪辑要求

- 剪掉 15–30 秒的研究等待时，**必须保留"点击 → 全屏研究过渡 → 最终真实落在目标公司画布"这三段**，不要直接跳到结果；
- 不做任何数值或结论的伪造、加速或移花接木；
- 产品当下若出现 AI 失败态（例如 `AI interpretation temporarily unavailable`、摘要降级为确定性摘要），**不要重录掩盖**——如实保留即是对的产品语言；
- 示例画布的琥珀色"录制示例"徽标必须始终可见，不得裁掉——它是"这是示例数据"的诚实标记。

## 如果录制失败

按既有原则：不要为了录制反复消耗时间，也不要生成占位视频。此时交付：

1. 本脚本（`演示脚本.md`）；
2. `产品走查.md` 的最终截图与逐步说明；
3. 明确说明"演示视频需在具备录屏能力的环境手动录制"。

本次提交即采用这一方式（见 `SUBMISSION.md`）。

## 录制前必读

本脚本的每一幕都应在 `docs/final/全景走查.md`（同目录下的 ~40 行清单）里有对应的真实指针实测行；**清单里有 FAIL 的那一幕不要录**，先修再录。
