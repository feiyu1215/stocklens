## 三、过程中的三个探针陷阱（写下来给下一次用）

这三个坑都真实产出过**假 FAIL**，不要踩第二次：

1. **研究库的表不是 `<table>`**：库行是 div 栅格渲染，`tbody tr` 恒等于 0。数行要用"叶子节点的文本像 6 位股票代码（`/^\d{6}\.(SZ|SH|BJ)$/`）"来识别。
2. **`/research` 与 `/` 是同一组件的两个 surface**（`data-surface="start" | "library"`），切换靠 ▦ 而非路由跳转。直接 `goto('/research')` 会渲染 library 面，但页面里仍然同时存在 start 面的文本节点——**按整页文本判断"在不在研究库"会误判**，要看 `data-surface`。
3. **同一个 context 连续采样会互相污染**：曾出现"第二次打开示例画布后库行不再标录制示例"的 FAIL，独立干净 context 复跑 3 次全部 PASS（画布徽标 + 「可体验示例 / 录制示例」+ 提示文案齐全）。涉及本机状态的检查要用独立 context。
