# 双公司对比 P0 —— PRD（方案 C 收敛版）

- 日期：2026-10-08
- 状态：已批准（两轮外部 AI 评审收敛 + 作者确认，直接进入开发）
- 前序文档：`2026-10-08-全局AI对话入口与两公司对比-评审方案.md`（方案 A/B）、外部评审两轮记录（方案 C，见对话归档）

## 一、结论：采用方案 C（对比能力先行，AI 入口渐进）

外部评审推翻了原方案 A 的排序（悬浮球先行），改为：

- **P0（本期）**：客户端双公司对比——研究库选两家 → 专属对比页，逐指标并排 + 证据溯源，**第一期完全不依赖 LLM**；
- **P1**：统一轻量 AI 入口——各页面上下文感知入口（不做常驻悬浮球），支持导航 / 知识解释 / 单公司追问 / 打开对比；
- **P2**：双公司 AI 综合分析——跨公司证据引用 + 可比性校验 + 受约束摘要（此阶段才需要证据 ID 命名空间合并）；
- **P3**：研究库级 AI 分析——只基于本机已缓存数据做可核验筛选（如"哪些公司数据过期"），不假装覆盖全市场。

### 评审纠正了原方案两处技术判断（已采纳）

1. **证据 ID 不是 P0 的前置改造**。两份 payload 保持独立、客户端并排展示，用复合身份 `{stockCode, evidenceId}` 在展示与引用层定位证据即可；只有 P2 跨公司合并喂给 LLM 时才需要命名空间处理。
2. **研究库有记录 ≠ 研究数据可用**。payload 有配额淘汰机制，对比入口必须分别验证两份数据存在且可解析；缺失时提示重新生成，**绝不把缺失数据显示为零**。

## 二、P0 范围

### 2.1 入口

研究库矩阵面新增「对比」模式开关（默认关闭，≥2 家公司时可用）：

- 开启后行变为可选项（点击切换选中，最多两家；再多点击不生效并提示）；
- 恰好选中两家时出现「开始对比」；「退出」结束对比模式；
- **默认状态下研究库行导航行为完全不变**。

### 2.2 对比页

路由 `/research/compare?stocks=<A>,<B>`，数据全部来自本机 IndexedDB 存量 payload（`loadResearch`），零网络、零模型调用。

- **固定指标目录**（不依赖 AI 生成的动态维度，保证口径稳定），四组九项：
  - 成长：营收同比·累计（FIN_REVENUE_YOY_YTD）、净利润同比·累计（FIN_NET_PROFIT_YOY_YTD）、经营现金流同比·累计（FIN_OCF_YOY_YTD）
  - 盈利：销售毛利率（FIN_GROSS_MARGIN）、销售净利率（FIN_NET_MARGIN）、加权平均 ROE（FIN_ROE）
  - 现金流：经营现金流/净利润（FIN_CFO_TO_NET_PROFIT_YTD）
  - 估值：市盈率 TTM（VAL_PE_TTM）、市净率 MRQ（VAL_PB_MRQ）
- **数值直接来自结构化 metrics（MetricResult.value），不从 AI 文本提取**；不可用指标展示 `unavailableReason`，目录中无此指标如实标注。
- **可比性三级判定，由确定性规则引擎决定，AI 不参与**：
  - `可比较`：双方 available 且 `period`（报告期/数据日期）一致 → 计算差值（% 单位指标的差值单位是 pct 百分点差；x 单位指标为绝对差）。差值是中性事实，**不做"谁更好"的着色或判断**；
  - `仅供并列参考`：双方 available 但 period 不一致 → 只并排展示，不算差值；
  - `不可比较`：任一方 unavailable 或缺失 → 不展示推导结果，说明原因。
- **每项指标可展开"证据与口径"**：双方证据 statement（复合身份 `{stockCode, EV_FACT_<metricId>}` 查找，互不串线）、calculationMethod、sourceFields（来源/字段/报告期）。
- **数据可用性三态**（B 的补充）：`不存在`（payload 被清理 → 提示重新生成）/ `存在但不完整`（metrics 缺失 → 只展示可验证部分）/ `正常`；每侧头部展示研究生成时间。
- **示例数据纪律**：每侧明确标注是否为录制示例（`recordedSample`）；一侧真实一侧示例时给显著混合警示，不产生"貌似真实的比较"。
- 页面含：返回研究库、双方各自研究空间入口、三级可比性图例。

### 2.3 不做什么（P0 边界）

- 无 AI 摘要、无胜负判断、无评分排名（P2）；
- 不改证据 ID 生成层与存量 payload；
- 不做两家以上对比；
- 不做画布证据锚点深链（行内展开证据文本已满足溯源，深链归 P1+）。

## 三、验收标准（六项，来自评审收敛）

| 验收项 | 完成标准 |
|---|---|
| 研究库入口 | 能选中且仅选中两家公司，进入专属对比页 |
| 数据可用性 | 检查双方 payload，缺失或不完整时正确提示，不伪造零值 |
| 指标展示 | 数值直接来自结构化 metrics，采用固定指标目录 |
| 可比性判断 | 按确定性规则标记状态，仅对可比数据计算差值 |
| 证据溯源 | 使用公司代码+证据 ID 复合身份，正确打开对应证据内容 |
| 交互闭环 | 返回研究库、进入双方研究空间、示例与真实数据明确区分 |

## 四、测试矩阵（至少覆盖）

正常可比（同报告期）、单方缺失、不同报告期（并列参考）、相同原始证据 ID（复合身份不串线）、演示数据混用、payload 不完整、% 与 x 两种差值口径、入口最多两家约束。
