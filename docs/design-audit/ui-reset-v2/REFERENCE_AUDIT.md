## Unseen World 可观察语法（复现依据，逐条）

1. World 占满整个 viewport —— 无页面容器
2. 没有右侧固定空白栏
3. 没有 Dashboard 容器 / 面板
4. 没有中心 Hub
5. 没有规则卡片矩阵
6. Drag 整个视觉世界就是导航（grab 光标）
7. 对象散布在空间里（不等大、部分出血裁剪）
8. 大量空间由视觉内容承担，而非 UI 边框
9. Chrome 极少（wordmark + 主导航 + ©）
10. 一屏真正强调的对象很少，但尺度足够大
