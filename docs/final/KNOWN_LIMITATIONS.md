# Known Limitations

本文件只列**当前真实存在**的限制。产品对每一项都有明确行为——要么绕开，要么如实呈现，不会假装它不存在。

---

## 1. 研究初始化需要约 15–30 秒

**事实**：首次进入一家公司时，Research Framer 与 Composer 两次真实模型调用占掉 94–97% 的时间（数据层取数 + 指标 + 证据仅 0.17–0.6 秒）。

**产品怎么做**：用**全屏研究过渡**承载这段等待——大字号目标公司身份、真实已等待秒数、五个中性占位（只表达"研究角度尚未解析"，不预写任何金融语义）、以及随时可用的「← 返回上一家公司」。**不做**假进度条、百分比或剩余时间预测：在没有可靠预测的前提下，那些数字就是编造。

**为什么不做流式/并行优化**：先测再优化。当前瓶颈已被定位到模型串行调用，而不是取数；在没有明确要求前不引入流式架构。

## 2. 桌面优先的空间化界面

**事实**：这是一个以 1440×900 为设计基准的研究画布。

**产品怎么做**：在 1280×800 与 1440×900 下全部交互可用（已逐项实测）。在窄屏（如 390×844 手机宽度）页面不会空白、不会横向溢出、AI Lens 仍可达，但**空间型交互不在支持范围内**：相机缩放下限（0.65）无法把 1440 宽的设计世界装进 390 px，维度会落在视口之外。v5 没有移动端专用布局——这是明确的范围边界，不是"移动端简化版"。

## 3. Follow-up 是原子 JSON，不是流式

**事实**：`POST /api/followup` 一次返回完整结果。

**产品怎么做**：界面上的 `Reviewing current evidence…` 是**进度态**，不假装 token 流；`■ Stop` 只取消浏览器侧请求，文案只说「Stopped by you」，**不声称服务端计算已取消**（后端没有取消端点）。失败时只在线程内提示并提供 `Retry answer`，不影响画布与证据。

## 4. 模型看不到对话历史

**事实**：每一轮追问只携带当前 scope（公司/维度/claim/证据）与相关证据 ID；后端**不接收**历史轮次。

**产品怎么做**：线程历史完整保留在客户端供用户回看，scope 变化时插入 `CONTEXT CHANGED → …` 分隔线而**不清空历史**；界面不暗示模型记得上一轮。这是诚实的做法——多轮上下文能力当前不具备，就不呈现成具备。

## 5. 不支持的能力一律返回 UNKNOWN

**事实**：扶摇当前不提供新闻/公告类接口；历史估值序列与部分行业字段未接入。

**产品怎么做**：对应维度直接落为 `unknown`，并列出**缺什么**（例如「同行财务位置暂无法验证」「未接入历史估值序列」）。`UNKNOWN` 是正式结果，带 `unavailableReason`，在 UI 上以独立分区呈现，文案明确说明"这不是负面证据，也不是系统错误"。**绝不**用模型补一段听起来合理的解释。

## 6. 同行比较是行业级，不是成分股级

**事实**：已实现的是**行业级**比较——个股 PE/PB 与行业成分股中位数之差（带有效样本数，过滤 PE≤0），以及个股相对行业指数的区间表现。

**未做**：逐家成分股的财务报表级对标（营收/利润/现金流横向排名等）。产品对此的态度是显式声明未接入，而不是用行业均值冒充逐家对比。

## 7. 数据"过期"缺少机制性防护

**事实**：数据缺失 → `unavailable` + reason（绝不以 0 冒充）、冲突 → `conflict` 信号、调用失败 → 局部降级，这三类都有确定行为并被单测锁定。但**没有**新鲜度/时效守卫：如果上游返回一份日期久远的数据，系统只会如实展示其 `period`，不会主动降级或提示"数据可能过期"。

**影响**：用户需要自行看期次判断时效。这是当前真实的缺口，未做掩饰。

## 8. 当前已知的视觉与文案问题（未修）

产品在以下四处有可见但不影响操作的问题，如实登记：

- **Reading 头部路径行与标题重叠**：当某条 claim 或证据处于活跃状态时，列内会渲染一行「公司 / 维度 / Claim 0N / Evidence ①」的路径，它与从画布飞入的维度标题在垂直方向上重叠约 19 px（标题在前）。无活跃 claim 时布局正常。复现：进入 Reading → 点击任意 claim 的 ①②③ 证据锚点。
- **首次访问提示卡文案**：写「观看 60 秒演示」，而 Guided Demo V2 实际为 6 场景 / 50 秒。
- **取消等待的确认文案不可见**：取消公司切换时会设置「已取消等待」，但过渡层在同一次渲染中卸载，该文案没有机会显示。
- **整页刷新不恢复画布快照**：会话内的缓存返回完全正常（实测 15.8 ms、零新增 init），但整页 reload 后画布回到默认相机与默认位置（AI 线程历史会从 sessionStorage 恢复）。原因是启动路径只写入会话缓存、不应用画布快照，且维度 ID 每次生成都不同，旧位置无法映射。

## 9. 明确不在产品范围内

没有用户系统与账号；不持久化诊断历史（刷新即重新研究）；不做 K 线图与图表库；不接入新闻/公告；不做语音；不做多公司并列对比视图；不提供投资组合、自选股推荐或任何形式的收益预期。

## 10. 关于"没有做到的"与"有意不做的"

- **没有做到**：上面第 7 条（过期数据防护）是真实缺口；第 8 条的四项是已知未修问题。
- **有意不做**：流式输出、假进度、评分/评级、买卖建议、涨跌预测、用 LLM 计算数字、在数据缺失时生成"正常"结论——这些是产品纪律，不是遗漏。
